Sektion 01

Marke & Logo

Das ekowai-Logo besteht aus zwei Teilen: dem Tropfen-Icon (Gradient, symbolisiert Wasser und Kreislauf) und dem Wortmarken-Schriftzug „ekowai" in Poppins Light. Beide Elemente dürfen nur in den genehmigten Kombinationen und Farben eingesetzt werden.

Marken-Gradient

Der Gradient ist die visuelle Signatur von ekowai und darf ausschließlich für das Logo-Icon, illustrative Elemente auf der Landing Page und Marketing-Material verwendet werden. In der App (nach dem Login) wird der Gradient nicht eingesetzt.

Sektion 05

Komponenten

Navigation

Die App-Navigation ist sticky, mit 80% Hintergrundopazität und Blur. Das Logo als Wortmarke (SVG) links, Navigation-Links rechts. Keine Icon-Navigation.

Buttons

Keine border-radius — alle Buttons haben scharfe Ecken. Drei Varianten: Primary (gefüllt), Outline (Rahmen), Ghost (transparent). Kein Gradient auf Buttons.

Sektion 07

Regeln & Do / Don't

App — Was ist erlaubt
✓ Erlaubt in der App
  • Hairline-Rahmen (1px, --hairline)
  • Monospace-Labels für alle Metadaten
  • Dezentes Hintergrund-Grain (body level, sehr subtil)
  • Paper / Paper-2 als Hintergrundfarben
  • Akzentfarbe --accent für interaktive Elemente
  • Logo-Tropfen mit Gradient (nur im Logo)
  • Scharfe Ecken (border-radius: 0)
  • Corner-Ticks bei Formular-Karten
  • Tabellarische Zahlen (Tabular Nums)
  • Semantische Farben für Status (Erfolg/Warnung/Fehler)
✗ Verboten in der App
  • Farbverläufe (außer im Logo-Icon)
  • Box-Shadows / Drop-Shadows
  • Abgerundete Ecken (border-radius > 0)
  • Kursive Überschriften
  • Animationen außer transition-colors / transition-all für Hover
  • Gradient-Text / Clip-Path-Effekte
  • Hintergrundbilder oder Texturen
  • Große atmosphärische Farbflächen
  • Backdrop-Blur in Content-Bereichen (nur Nav)
  • Bunte Buttons (außer semantische Zustände)
Landing Page — Zusätzlich erlaubt
✓ Nur Landing Page
  • Radiale Hintergrund-Gradienten (sehr subtil, max. 6% Opazität)
  • Kursive Überschriften-Akzente (sparsam, 1× pro Sektion)
  • Großes Hero-Layout mit visueller Gewichtung
  • Editorielle Listenelemente (— Monospace-Bullets)
  • CTA-Buttons mit Gradient-Fill (Eko-Green → Eko-Blue)

Sektion 08

Token-Referenz

Alle Tokens sind als CSS Custom Properties in src/app/globals.css definiert und über Tailwind-Klassen verfügbar.

/* src/app/globals.css — @theme */ /* Hintergründe */ --paper: #f8f5ee /* bg-paper */ --paper-2: #f1ece1 /* bg-paper-2 */ /* Text */ --ink: #0d1418 /* text-ink */ --ink-2: #2a3338 /* text-ink-2 */ --subtext: #5f6a72 /* text-subtext */ /* Linien */ --hairline: #d4cfc4 /* border-hairline */ --hairline-strong: #b8b1a2 /* border-hairline-strong */ /* Akzent */ --accent: #1a7a4a /* text-accent / bg-accent / border-accent */ --accent-2: #125c38 /* text-accent-2 / bg-accent-2 / border-accent-2 */ --accent-soft: #d0ead8 /* bg-accent-soft */ /* Semantisch */ --warning: #8a5a2b --warning-soft: #ecdfc8 --error: #7c2d2d --error-soft: #ecd5cf --success: #1a7a4a --success-soft: #d0ead8 /* Marken-Gradient (nur Logo + Landing) */ --eko-green: #00D061 --eko-blue: #009EE9 /* Schriften */ --font-display: 'Poppins', ui-sans-serif, system-ui, sans-serif --font-body: ui-sans-serif, system-ui, -apple-system, 'Segoe UI', sans-serif --font-mono: ui-monospace, 'SF Mono', Menlo, Consolas, monospace
Hinweis
Tailwind v4 — kein tailwind.config.ts. Alle Tokens werden direkt im @theme-Block in globals.css als CSS Custom Properties registriert.
