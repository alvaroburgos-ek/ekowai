## 4. Derived values (equations) + inheritance
- Eq. 1 `s` ← sqrt(Σ(`x_i` − `x_mean`)²/(`n` − 1)) (§16.4); Eq. 2 `L` ← 2·`K`·`sigma`/sqrt(`n`) (§16.5, quoted "L = 2Kσ/√n"); Eq. 3 `n` ← (2·`K`·`sigma`/`L`)² (§16.5 "el número de muestras necesarias es (2Kσ/L)²").
- Circularity: `n` is input to Eq. 1/2 and output of Eq. 3; `s` (estimate) and `sigma` (true) are separate fields — correct per standard, but `x_mean` should be computed from rows, not typed. `n` consumed by ISO-5667-1-06 (CR-023).
- Cross-standard: `n` ↔ ISO-5667-10 `number_of_samples` (§4.3.1 "statistical techniques (ISO 2602, ISO 3534, ISO 5667-1)") — should inherit; `transport`/`safety` fields duplicate ISO-5667-6/-10 (`safety_regulations_considered` ↔ `risk_assessed_before_sampling` ↔ `safety_assessment_done`); `cooling_system_type` exists here (open_evaporative/once_through/closed_circuit) and in ISO-5667-10 (once_through/primary_secondary/closed) with different enums; `flow_proportional_sampling` ↔ ISO-5667-10 `composite_mode`.

## 5. Summary
Counts: 4 table-lookups / 4 repeatable groups / 11 conditionals / 3 equations.

Top 5 UX wins:
1. `confidence_level` → `K` looked up (2,58 … 0,67) instead of typed; then `n` computed and pushed to ISO-5667-10 `number_of_samples`.
2. Historical results as `x_i` rows → `x_mean`, `n`, `s` computed (replaces 3 typed statistics).
3. Sites as repeatable rows whose `water_situation_type` shows only the relevant §9–13 checks (groundwater purge/depth, sludge bore, cooling type, stormwater flow-proportional).
4. `flow_aspect` filters `flow_measurement_method` to the §21 subset.
5. `programme_type` switches between control-limit fields and target-statistic fields (§15).

Data-quality gaps: source is a 1980-edition Spanish translation (current ISO 5667-1 is 2020/2023 — clause numbers §16/§19–21 will not match a modern edition); no md transcript; `K` typed; `x_mean`/`n` typed; situation-specific CRs (016, 017, 019) fire regardless of `water_situation_type`; cooling-system enum differs from ISO-5667-10; unit "-" on enums/booleans; `parameter_list` free text.
