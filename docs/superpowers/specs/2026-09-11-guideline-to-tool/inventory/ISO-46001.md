## 4. Derived values + inheritance
Equations (4): C.1 `Win ← WD + R1 + R2 + R3`; C.2b `Wout ← O1 + O2 + O3 + O4`; C.3 `plant_recycling_rate ← (Rp + Rnp) / (Rp + Rnp + WD) × 100`; C.5 `process_recycling_rate ← Rp / (Wp + Rpp) × 100`. Transcript check (raw l.1106–1166): "Win = Wout (C.1)"; "WD + R1 + R2 + R3 = O1 + O2 + O3 + O4 (C.2)"; "(Rp + Rnp) / (Rp + Rnp + WD) × 100 % (C.3) where Rp is total reused/recycled water from the process; Rnp is total reused/recycled water not from the process"; "Rp / (Wp + Rpp) × 100 % (C.5) … Wp is incoming water to process; Rpp is reused/recycled water from process back to process." — prod matches.
Consumers: Win/Wout → -09; recycling rates → -04/-05.

Missing derived: `water_efficiency_indicator ← past_present_water_use / business_activity_indicator_value` (3.33 definition; no equation); Win vs `past_present_water_use` should be one quantity.

Re-typed duplicates: `past_present_water_use` (-04, m³) vs `Win` (-08, total water input) vs `WD` + `R1…R3`; `water_sources` (text) vs R-stream identities; `water_efficiency_objectives` (text) vs the five objective_* fields; `action_plan` (text) vs `improvement_verification_method`; cross-standard: total water input vs VSME `TotalAmountOfWaterWithdrawnFromAllSites` and ISO-59020 `VAIW`/`VTWW`, recycling ratio vs ISO-59020 `RWRR` (= VTWU / VTWW) — same site quantities entered in three standards.
