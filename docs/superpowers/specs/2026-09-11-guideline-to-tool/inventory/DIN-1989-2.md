## 5. Summary
Counts: table-lookup candidates 8 / repeatable groups 6 / conditionals 11 / equations 9.

Top 5 UX wins:
1. `filtertyp` gates everything: show only Typ-A / Typ-B / Typ-C fields and requirements (CR-03..06, Gl. 7 vs Gl. 8/9) — today all three sets are always required, so B/C filters fail A-checks.
2. DN as enum with EN 12056-3 Tab. C.1 lookup filling one `Q_max` symbol; collapse `Q`, `Q_max`, `Q_Zu_max` into one inherited value that drives Gl. 1/2/4/6.
3. Test steps as repeatable rows (Tab. 2 percentages, Q_Zu, Q_Ab, t) producing the η-curve and the documented η values, instead of one scalar pair.
4. Derive required `V_Rueck` minima from Q and compare with provided volume; derive `filtertrennwirkung_nachgewiesen` from η ≥ 0,7 and the DN ≤ 200 rule.
5. Prüfstoffe rows from Tab. 3 (mass per 1000 l × Prüfmedium volume) with recovered masses per Stoff feeding Gl. 7–9.
