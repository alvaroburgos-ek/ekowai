## 4. Derived values (equations) + inheritance
- Formula 1 `sampling_day_k` ← `A` + 365·`k`/`number_of_samples`; Formula 2 `sampling_week_k` ← `A` + 52·`k`/`number_of_samples` — both registered; should generate n rows rather than one k. `A` random offset should be validated against its range (−365/n…0).
- Formula 3 `V_n` ← `V_final`·(`M3_n`/`M3_total`) — per bottle.
- `number_of_samples` should be inherited from ISO-5667-1 `n` (§4.3.1 refers to ISO 5667-1 statistics) — today typed here.
- Cross-standard duplicates with ISO-5667-6: `transport_temperature`, `preservation_per_iso5667_3`, `normative_references_consulted`, `sample_traceability`, `qa_qc_per_iso5667_14`, `gloves_used`, `written_contamination_instructions`, safety block; with ISO-5667-1: `cooling_system_type` (different enums), `sampling_objective_defined`/`objectives_defined`; with ATV-A-704E: `sample_type_definition` ↔ `sample_type`, `composite_mode` ↔ `sampling_method`; with DWA-M-1200-2: `probennahme_typ` (mischprobe_24h/qualifizierte_stichprobe/stichprobe) — same concept, third enum.

## 5. Summary
Counts: 8 table-lookups (text rules, no numeric tables) / 7 repeatable groups / 15 conditionals / 3 equations.

Top 5 UX wins:
1. Sampling schedule generated: `number_of_samples` (inherited from ISO-5667-1) + `sampling_period` → Formula 1 or 2 chosen automatically, `A` drawn within its range, n dated rows produced.
2. `composite_mode` drives the automatic-sampler block: CVVT/CTVV show flow-link + unit-volume/velocity limits; CTCV shows the per-bottle Formula 3 rows with Σ checks.
3. `specific_site_type` shows only the §5 checks for that site (sewer depth/restriction, WWTP objective/bypass, cooling run-off/biocide).
4. Limits switched by context instead of hard-coded: 5/30 min by composite duration, 0,5/0,3 m/s by tube bore, 50/25 ml by pump type, mechanical/manual homogeniser by volume.
5. One shared "Probenahme-QA" block (transport 5 ± 3 °C, ISO 5667-3 preservation, ISO 5667-14 QA, traceability, PPE) inherited across ISO-5667-1/-6/-10 and ATV-A-704E instead of four re-typed copies.
