## 4. Derived values (equations) + inheritance
- Eq. A.1 `l` ← 0,13·`b`²·`c`·(0,7·`c` + 2·`g`)/(`g`·`d`) — consumer ISO-5667-6-03 (compare with distance to confluence). `g` is a typed input (should be constant 9,81). Formula rendering in the transcript ("0,7c + 2 g" with a stray radical on the line above) suggests the original may read (0,7·c + 2·√g) — verify against the PDF/ISO original before relying on the prod formula.
- Eq. 2 `sampling_depth_below_surface` ← `preferred_subsurface_depth` (trivial identity; both typed, both VR ≥ 30 → re-typed duplicate; should be a single default 30 cm).
- Missing: `sampling_point_count` ← count(rows); `heterogeneity_samples_count`/`travel_time_flows_count` ← counts; `homogeneity_status` ← spread of test samples.
- Cross-standard duplicates: `transport_temperature` (2–8 °C) identical in ISO-5667-10; `preservation_per_iso5667_3`, `normative_references_consulted`, `sample_traceability_maintained`/`sample_traceability`, `qc_qa_per_iso5667_14`/`qa_qc_per_iso5667_14`, `disposable_gloves_used`/`gloves_used`, safety fields — all re-typed in ISO-5667-10 with slightly different symbols; `sampling_depth_below_surface` ↔ ISO-5667-10 `grab_depth_below_surface` (both 30 cm).

## 5. Summary
Counts: 5 table-lookups (only Annex A carries numbers) / 6 repeatable groups / 14 conditionals / 2 equations.

Top 5 UX wins:

2. Heterogeneity-test samples and travel-time measurements as rows so the ≥6 / ≥3 flows / ≥5 flows counts and `homogeneity_status` are computed, not asserted.
