  therefore targets PRODUCTION. Production rejected the auth-admin call ("Invalid API key") before any

  `tests/harness/*` runs from this worktree; the `src/lib/actions/__tests__/*.integration.test.ts` suites
  need an embedded-DB harness first.

  run; their STAGED SQL is a later data-only wave that needs no redeploy.
