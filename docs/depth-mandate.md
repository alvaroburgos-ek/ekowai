## The bar (as dictated)

A guideline is not finished until, for that guideline:

1. **Every equation** is checked symbol-by-symbol against the printed source.
2. **Every table row and threshold** is verified against the printed source.
3. **Every gate is fired** — not merely shown to exist.
4. **Every field is classed and page-traced.**
5. **Every cross-reference is boundary-clean** (per the CONTENT BOUNDARY RULE).
6. **Harness-proven through the real save path** — not static inspection.
7. **Hours as needed. READY-TO-USE is the finish line.**

## Binding interactions with existing ratified doctrine

The mandate does **not** override anything already ratified. Where they meet:

- **It cannot manufacture READY-TO-USE.** Four residue classes are human-only by design
  (modal-verb severity ratification, figure-derived nodes, NR-without-threshold,
  Gelbdruck risk), plus never-invent removals. A guideline whose remaining items are
  ratification-only is **DONE-PENDING-SIGNATURE**, not incomplete work. Reporting it as
  READY-TO-USE would be the R-5 failure (fabricating completion to match a premise).
- **Axes can be legitimately vacuous.** VDI-3814-Blatt-2-1 has zero equations, so axis 1 is
  *absent*, not skipped. Say which axes are N/A; never imply coverage that had no surface.
- **Axis 3 ("every gate fired") is the one that catches real bugs.** The `_PROGRAM-REPORT`
  F-4 finding — three `<ident> >= <ident>` block gates that fire but never enforce — was
  invisible to static map inspection and caught only by the execution harness. Axis 6 is
  therefore the mandate's load-bearing clause, not its ceremonial one.
- **Depth does not license writes.** Author-only migrations, WRITTEN-NOT-APPLIED, one
  commit per standard, human applies. Depth changes how much is *verified*, never who
  *ratifies*.
- **Never block on a missing source** (standing-order): cap per SR-3, list as
  source-absent, keep moving. 8 standards are currently page-unverifiable.

## Reporting rule

Every wave report states, per axis, one of: **covered** / **N-A (absent surface)** /
**not reached**. "Not reached" is stated plainly, never left to be inferred from omission.
