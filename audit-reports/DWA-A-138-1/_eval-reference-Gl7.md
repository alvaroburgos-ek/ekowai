# Eval-Reference — DWA-A 138-1, A138-12, Gl. 7 (A_S,m)

`A_S,m = (A_S,min + A_S,max) / 2` — Mittelung der Versickerungsfläche, §5.3.3.6.

| Input | Value | Unit |
|---|---:|---|
| A_S_min | 80 | m² |
| A_S_max | 120 | m² |

A_S,m = (80 + 120) / 2 = **100.000 m²**.

Precision ± 1 × 10⁻⁹. Both inputs must carry `m²`. Mismatch → manual_required.
