# Gl. 24 (A138-18) — q_VS specific outflow of perforated infiltration pipe


> **NOTE — fixture-output framing.** The numeric output shown below (e.g. V_VA = … m³) is the engine's output for the **specific example inputs in this file** (a Heinsberg-like reference fixture). It is **NOT** a normative constant of DWA-A 138-1. The standard defines only the formula; the number changes when the engineer enters different project inputs.

`q_VS = 0.1 · az_SOE · A_SOE · 10⁻¹` — §6.4.2.

| Input | Value | Unit |
|---|---:|---|
| az_SOE | 10 | 1/m (Sickeröffnungen je Meter) |
| A_SOE | 1 | cm² (Größe der Öffnung) |

q_VS = 0.1 · 10 · 1 · 0.1 = **0.100 l/(s·m)**.

Source-Default-Spannweite: Kiessand ≈ 0.2 l/(s·m); Kies (16/32) ≈ 5 l/(s·m). Engineer-Wahl je nach Schüttmaterial. Sibling: l/(s·m) — kein anderes Equation produziert diese Einheit (consumed by Gl. 25).
