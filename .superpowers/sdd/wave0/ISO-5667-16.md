## Findings by defect class

### dead gate — unsupported grammar (35 CRs)  [PRIMARY]
Per `reference_wizard_compliance_gates.md`, `evaluate.ts` supports single comparisons only — no
`eq`/`==`, no `IN {}`, no chained `A>=x AND A<=y`, no multi-clause `A AND B`, no bare
`IS NOT NULL` truthiness, no `manual`. EVERY CR condition uses at least one unsupported form ⇒
none fire. Breakdown:
- `IN {…}`: CR-004, CR-020(block).
- chained range `A>=x AND A<=y`: CR-005, CR-008, CR-016.
- `eq`/`==`: CR-002(block), CR-003, CR-007, CR-010, CR-011, CR-012, CR-034.
- multi-clause `A AND B`: CR-001, CR-028, CR-031, CR-035.
- `IS NOT NULL`: CR-006, CR-013, CR-019, CR-021, CR-024, CR-025, CR-029, CR-032.
- `manual`: CR-030 (see own sub-class below).
- single-symbol `>=`/`>`/`<=` (may parse): CR-009, CR-014, CR-015, CR-017, CR-018, CR-022,
  CR-023, CR-026, CR-027, CR-033 — but several of these are producer-starved or vacuous (below).

### dead gate — non-evaluable condition (1)
CR-030 `condition: "manual"` — placeholder, no fired_by symbol, no reachable-fail. Never fires.

### #22 hand-enterable-derived (2)
`BCF` (EQ-01) and `CT_50` (EQ-02) are engine-`derived` yet ALSO hand-enterable `number` fields
with validation `BCF>=0` / `CT_50>0`. Violates template invariant #4.

### inequality/verdict-as-producer (2)
CR-026 (`BCF>=0`) and CR-027 (`CT_50>0`) gate on the derived output symbol of their own equation;
a hand-typed value satisfies the gate without the equation running (producer-starved). Both are
also near-vacuous (any physical value ≥0 / >0).

### guidance-as-block (2)
ISO 5667-16 is guidance ("Guidance on biotesting", modal "should") yet CR-002 and CR-020 are
`severity: block`. Normativity ruling required. (Also both dead per grammar → block enforcement
is currently nil regardless.)

### missing-doc dependency (2 docs)
- ISO 5667-3 (§2 normative ref; preservation/handling) — **NOT in library** (prod `standards` has
  no ISO-5667-3). CR-002 satisfaction + §5 preservation content (section-03) cap NR.
- ISO 8466 (§12.3 statistical evaluation) — **NOT in library**. Statistical-evaluation content of
  section-08 caps NR on ISO-8466-governed calibration detail.
- (ISO 5667-10, §2 — IN library, prod code `ISO-5667-10`; no cap.)

### scaffold-vs-source sections (structural, decision-point)
44 sections are generic scaffold codes, not source clauses; source structure survives only in
`clause_reference` strings. Section nodes cannot be VA independent of the PDF gap.
