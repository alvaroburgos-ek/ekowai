## Findings by defect class
- **dead gate (literal-`TRUE`) ×2** — CR-033, CR-038 have `condition = "TRUE"`; no reachable-fail,
  can never warn. Cross-reference markers (ISO 14001; ISO 14005 Anhang B) mis-encoded as CRs.
  [[dp-iso14004-true-gates]].
- **whole-standard non-enforcement (0 block / 38 warn) ×1 systemic** — nothing blocks. Correct for
  a "should" guidance standard, flagged so it is not mistaken for a mis-severity bug.
  [[dp-iso14004-all-warn]] / [[dp-iso14004-guidance-normativity]].
- **greedy-AND multi-field gate ×10** — CR-002/003/006/011/012/013/015/016/028/029/031 AND 2–3
  not-nulls; all-or-nothing warn, operator cannot see which sub-field is missing.
  [[dp-iso14004-greedy-and]].
- **duplicate-predicate CRs ×3** — CR-004 dup of CR-001 (anwendungsbereich NOT NULL); CR-036 dup of
  CR-022 (kommunikationsprozess NOT NULL); CR-035 dup of CR-028's auditprogramm leg. Redundant warn.
- **modal/optional mismatch ×1** — CR-014 gates `verpflichtung_verzeichnis == true` although its own
  source_quote says such a register "könnten" (optional). Warn-severity, low risk.
- **clause-drift note in source_quote ×1** — CR-037 quote embeds "(Klausel von §6.1.2.4 auf
  §6.1.2.3 korrigiert)"; editorial note in a verbatim field. [[dp-iso14004-cr037-clausefix]].
- **enum value nodes without pinned page ×10 (VC ceiling, not a defect)** — enum option-lists carry
  a `regulation_reference` but no per-option printed page. [[dp-iso14004-enum-pages]].
- **field-level `source_quote` NULL ×62 (systemic)** — traceability lives only at CR level; fields
  are `engineer_input` so a printed value is not expected, page derivable from clause_reference.
- **NOT present:** #22 hand-enterable-derived, inequality/enum/verdict-as-producer, F-4 var-vs-var —
  structurally absent (0 equations, 0 derived fields).
