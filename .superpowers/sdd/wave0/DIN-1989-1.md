## Findings by class
1. **Dead gate (1):** CR-12 `rueckstauschutz_art IN {rueckstaufrei,hebeanlage,rueckstauverschluss,nicht_erforderlich}` — the IN-set is the ENTIRE enum domain → tautology, can never fail (block severity, inert). Also omits the §14 level-conditional rule (Überlauf unter Rückstauebene → real Schutz mandatory; `nicht_erforderlich` should be gated on level data).
2. **Phantom-field / NOT-NULL gate (1):** CR-10 `V_n IS NOT NULL AND E_R IS NOT NULL AND BW_a IS NOT NULL` — only checks non-null of three already-required fields; never enforces §16.3.8's `V_n = 6% * min(BW_a,E_R)`; redundant with the required-field check → near-dead.
3. **Inequality/threshold under-enforcement (F-4 context) (1):** CR-04 `speicheroeffnung_dn >= 200` but Tab.2 (p.15) mandates ≥ 600 mm for oberirdisch > 3000 l AND ALL unterirdisch; only oberirdisch ≤ 3000 l may be ≥ 200. Underground tank @ 300 mm PASSES but violates Tab.2. Gate should be conditional on `speicher_aufstellung`+volume. Also field validation_rule = `>= 600` CONTRADICTS the CR `>= 200`.
4. **#22 hand-enterable-derived (4):** `E_R`, `BW_a`, `V_n`, `mindestwasservolumen` are `number` fields (is_required, hand-enterable) that each equal an equation output (Gl.1/2/3/4). Lets an engineer type a V_n violating the 6% rule that no gate catches. → dp-01.
5. **Inequality/enum/verdict-as-producer:** none of the CRs use a computed verdict/eta as a gate input (unlike DIN-1989-2 CR-08); the sizing rule simply isn't gated at all (folds into #2/#4).
6. **F-4 var-vs-var non-enforcement:** the §16.3.8 comparison `V_n vs min(BW_a,E_R)*0,06` is a var-vs-var relation the encoding never enforces (CR-10 checks null only). Named under #2.
7. **Double-producer / single-owner (1):** `BW_a` is `produces::` by BOTH Gl.(2) (personenbezogen) and Gl.(3) (flächenbezogen) with no combine rule/selector; §16.3.7 text ("setzt sich zusammen aus … und …") implies additive. → dp-02.
8. **Greedy-AND (1):** CR-13 `inbetriebnahme_fachkundig AND inbetriebnahmeprotokoll` (both §17.2-required, defensible but non-granular; `probelauf_durchgefuehrt` also §17.2 but excluded → partial coverage). CR-14 partial-coverage: gates only `wartung_fachkundig`, not the Tab.5 intervals / `filter_reinigung_jaehrlich`.
9. **SR-2 range / normative-lookup not machine-applied (2):** Tab.3 `e` (Ertragsbeiwert) and Tab.4 `P_d`/`BS_a` are re-entered as free `number` fields, not derived from the normative table by `auffangflaechen_art`/`nutzungsart`; Tab.4 gives ranges (Bewässerung 100–200, 80–150 l/m²) with no selection record (F-7).
10. **Modal-verb scope (1):** §10 "muss überwacht … sollte anzeigbar" → CR-08 block severity on a mixed muss/sollte sentence. → dp-03.
